# Research Iteration: Issue #$1

Issue #$1 already has one or more answers from you, and there are follow-up comments from the issue author.

## Task

1. Determine the current repository.
2. Read issue #$1 and all comments in chronological order.
3. Identify the open points:
   - Which questions did the issue author leave open or want to dig deeper into?
   - Which aspects are newly requested?
   - Which previous findings are being challenged?
4. Work on the open points. Do additional code research if needed.
5. Post the answer as a new comment. Up front, make explicit which question(s) you are responding to — e.g. "Response to the follow-ups on X, Y, Z."

## Constraints

- Language: English
- Markdown
- No code changes, no commits
- Address only the open points — do not repeat earlier findings unless they are being challenged
- If a question falls outside the original RESEARCH scope: flag it and suggest opening a new issue
- If the issue number is missing: ask, do not guess
